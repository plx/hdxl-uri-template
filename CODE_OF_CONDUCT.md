# Code of Conduct

HDXLURITemplate welcomes focused, respectful technical collaboration.

## Expected conduct

- Discuss code, evidence, and user impact rather than personal attributes.
- Give specific, actionable feedback and allow others to correct mistakes.
- Respect privacy, coordinated vulnerability disclosure, copyright, and
  provenance.
- Keep issues and pull requests on topic; move unrelated work to a separate
  thread.
- Assume good intent while remaining precise about safety and correctness.

## Unacceptable conduct

Harassment, threats, discrimination, sexualized attention, doxxing, deliberate
disclosure of secrets or vulnerabilities, sustained disruption, and personal
attacks are not acceptable in project spaces.

## Scope and enforcement

This policy applies to repository issues, pull requests, reviews, and other
spaces where someone represents this project.

Maintainers may edit or remove content, close or lock threads, reject
contributions, or restrict participation when conduct harms people or the
project. Enforcement should be proportional, documented without repeating
sensitive content, and applied consistently.

For visible repository conduct, use GitHub's report/block controls and flag the
specific content for maintainers without reproducing harmful material. Use
GitHub's private vulnerability-reporting route only for product or repository
security vulnerabilities, as described in [SECURITY.md](SECURITY.md).

This policy is project-authored and may evolve as project governance grows.
